# Namn

Kort beskrivning av när den här rutinen används — vilken fråga/situation
från en användare triggar den.

## Självbetjäning
Vad användaren kan/bör göra själv, utan att kontakta support. Länka till
[[../Funktioner/_Mall|rätt Funktioner-not]] om en finns.

## Om det kommer in som ett supportärende
Steg för steg — vad du som support/admin faktiskt gör, i ordning.

## Adminverktyg / fallback
Vad som finns i adminpanelen om självbetjäningen inte räcker eller
användaren inte kan logga in.

## Teknisk plats
Kod-referenser (endpoint, controller) — så rutinen går att verifiera mot
verkligheten igen senare, inte bara lita på minnet.

## Gränser / vad du INTE ska göra
Saker som medvetet INTE stöds, eller som kräver eskalering.
