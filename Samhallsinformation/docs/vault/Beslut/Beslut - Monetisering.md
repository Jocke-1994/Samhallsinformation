# Beslut - Monetisering

Ingen intäktsmodell är vald än, men två hårda gränser är satta (bekräftade
2026-09-12, se [[../Verktyg/Claudes-tankar|Claudes tankar]]):

- **Ingen reklam**, någonsin.
- **Ingen betalfunktion som ändrar hur appen fungerar** — inga
  prenumerationer som låser upp funktioner, ingen "betala för att slippa
  begränsning". Om något kostar pengar att bygga/driva är svaret antingen
  att inte bygga det, eller att finansiera det på ett sätt som inte
  påverkar upplevelsen (frivilliga gåvor, anslag).

## Bakgrund
Kom upp konkret i samband med SPAR-integrationen (#46/#55) — SPAR kostar
pengar per uppslag, och utan en bestämd intäktsmodell går den kostnaden
inte att motivera. Se [[Beslut - SPAR avfärdat]].

#141 (gåvor, redan öppet) fångar redan grundtanken — frivilliga gåvor,
inga prenumerationer. Det här beslutet breddar principen explicit till att
även gälla reklam och betal-påverkade funktioner rent generellt, inte bara
SPAR-fallet.

## Kvarstående
Ingen bestämd modell för vad som FAKTISKT ska generera intäkt (gåvor via
#141, anslag, eller inget alls tills vidare). Ta upp igen om/när
driftkostnaderna faktiskt blir ett problem.
